版本生成脚本（74 个）
=====================

一、用途
  本目录保存复赛周期内用于生成各版本提交件的脚本，按官方要求随包提供，
  供参考与复现。与投票池 32 个成员的对应关系见 ../投票池来源表.txt。

二、目录构成
  _*.py（67 个）    迭代过程中使用的生成、装配、测量与审计脚本（下划线开头）
  *.py （7 个）     早期脚本（模型接入、可视化、路径工具等）

  其中 _fuse_qwen.py 为各脚本共用的判据库（iou / norm / ordered /
  valid_cand / expected_ordinal_num / ordinal_axis 等几何与序数判据原语），
  其余脚本经 `import _fuse_qwen as F` 复用，以保证各版本判据口径一致；
  _md2pdf.py 为技术文档「AIC-2026-14375345-技术方案.PDF」的导出器。

  命名规律：多数生成脚本以 --stem / STEM 变量指定输出件名，可用
  `findstr /S /I "<件名>" *.py` 反查某一份是由哪个脚本生成的。

三、运行依赖
  1. 需与本工程的 code27b/ 同处一个项目根下（多个脚本经 src/ 导入模型与工具）；
  2. 部分脚本读取 submission_zips/semifinal/ 下的历史版本件（未随包分发）；
  3. 部分脚本面向当时的远程 GPU 环境（2×A100-40G 等），需具备相应硬件；
  4. 路径解析统一经 _sub_path.py；历史版本归类到分数子目录后，平铺路径不可直接使用。

四、共性说明
  · 所有脚本产出的均为模型推理结果的坐标帧，未使用任何真值信息；
  · 各版本之间为同一管线的不同处理策略与模型配置；
  · 迭代过程中的中间结论（含被否决的方向）一并保留，供完整参考。
