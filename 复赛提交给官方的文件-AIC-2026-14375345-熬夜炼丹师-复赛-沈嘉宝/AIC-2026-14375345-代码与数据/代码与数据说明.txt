data_outputs/   管线输入与运行记录

1) queries.json —— 赛题测试集索引
   来源：赛事官方随赛题提供，未做任何修改
   内容：5690 条查询的 Query ID → 三模态图像路径 + 英文查询文本
   复现：直接使用赛题原始文件

2) predictions_27b.json —— 主件（27B 全量推理输出）
   来源：Qwen3.8-27B 零样本推理；2026-10-05 02:01:15 起跑，07:23:51 完成；
         1295 张图像 / 5690 条查询；用时 19356.8 秒
   配置：configs/server_32b.yaml（multi_box 模式 / 三模态 split 输入 /
         低光红外增强 / 视觉特征缓存）
   复现：python scripts/infer.py --config configs/server_32b.yaml

3) predictions_ref.json —— 参照件（另一套解码输出）
   来源：同一推理工程的另一次独立全量推理输出（推理配置与主件不同）；
         为模型推理输出
   复现：调整 configs 中的推理配置后再次执行 scripts/infer.py，所得即参照件

4) consensus_pool.json.gz —— 投票池（32 套）

   用途：作为「多产物共识投票」的投票者集合。主件与参照件是被比较的两个候选，
         池内每个成员对每个真分歧位投出一票（该成员的框更接近主件还是参照件），
         由票数决定该位是否采纳参照件。

   结构：单个 gzip 压缩 JSON，内含 32 个成员（键名匿名化为 voter_01 … voter_32）。
         每个成员是一份完整预测：{"000001_001": [x1,y1,x2,y2], ...} 共 5690 条。
         仅保留 bbox 坐标（与 queries.json 重复的四个回显字段已省略），
         故 32 份合计约 1.7 MB。

   来源：本团队复赛周期内的版本集合，共 32 份 ——
           · 22 份为历史上提交并通过平台评测的版本（各有线上分数记录）
           · 10 份为本地运行版本（未提交）
         所有版本均出自本推理工程（同一套代码与配置体系），
         每份仅保留模型输出的 bbox 坐标；键名已匿名化为 voter_01 … voter_32。

   配置维度：共 15 项，见 scripts/pool_dimensions.py；例如：
           · model.name_or_path       模型规模（主件与参照件均为 27B）
           · inference.fusion_mode    融合模式 none / low_light / gated
           · inference.multimodal_input_mode  输入组织 split / fused
           · inference.chain_enforce  序数链修正 off / sort / project
           · inference.enable_depth_prior     深度先验开关
           · qwen.output_mode         single_box / multi_box
           · qwen.multi_box_id        ID 化输出开关
           · qwen.num_samples         候选采样数（>1 时启用采样投票）
         池即由上述维度取不同值、各自执行一次全量推理后汇总而得。

   复现：对每组配置重复执行 scripts/infer.py，汇总各次输出即可重建该池。

   校验：无任一成员与主件或参照件完全相同（可脚本核对）。

   固化：池以固化文件随包分发，使共识投票后处理可在离线环境下逐条复算，
         无需重新推理，保证提交结果可被第三方校验。

5) env_record.txt
   来源：实测环境快照（GPU / 驱动 / torch / transformers）

提交件 result.zip 由 scripts/consensus_vote.py 依据上述输入自动产出。
---------------------------------------------------------------------

方法要点
  1. 主件：Qwen3.8-27B 三模态（可见光 / 红外 / 深度）视觉定位，
     全量 1295 图 5690 查询。
  2. 后处理：多产物共识投票。仅对主件与参照件的真分歧位（互 IoU < 0.5）中
     「主件零票、参照件满票」的位置采用参照件框；其余位置保持主件。
  3. 阈值由投票一致性原理确定：只要出现任何异见票，即判定该分歧非单侧成因，
     保持主件不动——从而保证每一处改动均由全体产物的一致意见支撑。
  4. 后处理为确定性规则：同输入必得同 SHA256，输出可由管线逐条复算，
     不依赖任何运行期人工输入。
