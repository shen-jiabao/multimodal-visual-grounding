# 训练与评估脚手架（**未采用**）

## 一句话说明

本目录是**初赛期开发、最终未被采用**的训练与评估代码。放入提交包，是为了让
「数据预处理 → 模型训练 → 预测推理 → 评估」四个环节在代码上都有对应实现；
**不代表本方案使用了任何训练权重**。

## 最终方案为什么不用训练（有实测依据，不是省略）

1. **收益全部来自提示工程与确定性规则。** 序数层四条规则杠杆（水平轴文本推算 /
   候选自排序 / 垂直轴 / 回退点）均为零训练改动，线上净翻转 **+53 / +9 / +3 / +3**。
2. **最强的一次提升来自"换更强的开源模型"**，属**推理侧升级**，与训练无关：
   Qwen3-VL-32B-AWQ 替换 8B 直出，467 条改动 → **净 +82 条（+0.0144）**。
3. **全赛段无监督信号。** 复赛不提供 `test.json`（无真值），训练无从获得标签；
   所有判断都只能靠平台提交后的确定性得分——本项目的纪律是"**线上对照是唯一裁判**"。

## 文件

| 文件 | 作用 |
|---|---|
| `prepare_data.py` | 数据准备与校验 |
| `train.py` | 训练入口 |
| `train_competition.py` | 无 bbox 标注场景下的训练脚本 |
| `train_lora_gd.py` | GroundingDINO 的 LoRA 低秩微调 |
| `train_pose_classifier.py` | 检测后姿态分类器（正 / 侧 / 背） |
| `predict.py` | 推理入口（输出官方要求的 JSON） |
| `config.py` | 全局配置 |
| `evaluate.py` | ACC@0.5 / mIoU 评估 |
