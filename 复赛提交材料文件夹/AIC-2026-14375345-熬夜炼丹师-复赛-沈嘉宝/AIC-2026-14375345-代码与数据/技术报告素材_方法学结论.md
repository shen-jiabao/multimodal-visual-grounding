## 一、验证方法：无真值条件下的确定性读数

赛题不提供 `test.json`（**无任何真值**），常规的离线评估不可用。本项目的方法：

**① 归零法（zeroing measurement）** —— 交一件"测量件"，把**某个子集**的预测框换成必然错的
角落小框（面积 1e-4），其余子集保留真框；平台按**历史最高分**记录（测量件不拉低成绩），
而返回的得分数值**直接读出**其余子集的真实正确条数。

```
0.806 × a + 0.194 × b = 总分     （a = 非序数 4587 条准确率，b = 序数 1103 条准确率）
实测：a = 79.5%（错 940 条）｜b = 61.2%（错 428 条）
外部交叉验证：0.7459×5690 − 3648 = 596（序数层加入前）→ 675（加入后）= +79
             与五层实测净翻转之和 53+9+3+3+11 = 79 逐条吻合
```

**② 单变量隔离件** —— 每件只改一个层、其余层**逐位不动**（用断言机器验证），
使得分差可直接归因：

```
Δ得分 × 5690 = 净翻转条数          1 条 = 0.000176
```

**③ 预登记 + 小样判据** —— 每条杠杆在**跑之前**写定作用范围、闸门、事前预期与止损条件
（`_frozen_criteria.md` / `_prereg_B_prime.md` / `_prereg_C.md` / `_prereg_D.md`），
并用 200~300 条**分层小样**先测"改动率"与"改动条目 IoU 分布"两条判据。

## 三、★ 方法学结论（本报告的主要创新点）

### 结论一：**先验能否迁移，只取决于「替换路径与被替换那一层是否同类」**；「模型是否真升级」**不是必要条件**

> ★本条经过**两次自我更正**。初稿写的是"IoU 分布可预判升级/重掷"（据 B′ 与 D 的对照），
> 被实测推翻，见本节末；第二稿写"必须**同时**满足『模型真升级』与『同机制』"，
> 又被 2026-10-03 的跨代换模型实测**再次推翻**。以下为第三稿。

| 杠杆 | 被替换的那一层 | 模型更"强"？ | 是否同机制 | 改动面 | 实测净成功率 |
|---|---|---|---|---|---|
| 非序数 32B 重跑 | 8B 直接框 | 8B→32B ✓ | ✓ | 467 | **+17.6%** |
| 序数层同机制替换（B′） | 8B 直接框 | 8B→32B ✓ | ✓ | 87 | **+16.1%** |
| AWQ→bf16 精度修复 | 32B-AWQ 直接框 | 同族 ✓ | ✓ | 111 | **+9.9%** |
| **跨代换模型（Qwen3.8-27B）** | 32B 直接框 | **未证实**（27B < 32B、跨代、官方无接地指标） | ✓ | **519** | **+19.4%** |
| 同模型三模态输入（D） | 32B 直接框 | 32B→32B ✗ | ✓ | 128 | **−3.1%** |
| 序数层 SoM | 8B 直接框 | 8B→32B ✓ | ✗ 跨机制 | 66 | **−10.6%** |
| VLX-Seek 替换非序数 | 32B 直接框 | ✗ | ✗ 跨机制 | 846 | **−18.4%** |
| **打包复现对方规格（M）** | **混合层**：非序数 846（同机制）＋序数 484（**跨机制**） | 同模型 ✓ | **✗ 测量场景不同类**（提示词＋输入＋解码同时全改） | **1330** | **−22.4%** |

**修正后的判据（四条）**：

1. **同机制是必要条件**：纯跨机制的替换在本项目 **5/5 全负**（SoM −10.6%、VLX −18.4%）。
   ⇒ **"可迁移的不是规则文本，而是被替换那一层的性质"**。
2. **"模型真的更强"不是必要条件**：Qwen3.8-27B 参数更小（27B < 32B）、属跨代新架构、
   官方 benchmark **无任何视觉接地指标**（全部为编码 / agent / 推理类），
   事前据此判定"先验不可迁移、不给正数、**不是到 0.8 的路径**"；
   实测 **+100.7 条（8.8σ）**，是全部四次同机制测量中**最高的一次**。
3. **真正起作用的是**「**框层性质相同 ＋ 新模型的框与原层足够不同**」——
   差异本身就是收益来源（该件改动面 519，是 bf16 那次的 **4.7 倍**）。
4. **★（M 件新增）"同机制"必须理解为「同一测量场景」，而不是「两端都是 direct 框」**：
   M 件是同模型、两端框都由 VLM 直接输出，却在提示词（+5 条规则）、输入（三模态**合并成一张**）、
   请求粒度（multi_box）、解码长度（256→1024）、thinking（默认开→显式关）**五项同时改变**，
   实测净 **−22.4%**，是本表**最负**的一次。⇒ 判据里的"同机制"= **提示词／输入／解码口径
   逐项一致**；只满足"都是 VLM 直接框"是不够的。
   边界说明：M 的 1330 条改动**混合**了非序数 846（同机制）与序数 484（**跨机制**：
   老序数机制→direct），而平台只给总分 ⇒ **无法分解**，故本条**只**用于收紧"同机制"的定义，
   **不得**据它宣称"同机制也被推翻"。

**案件对照**：序数层 SoM 曾有约 6σ 的负面（净 −7），根因是它**跨机制**
（基线是 direct 框，替换用的是 SoM 流程）；而同一层、同一模型的 direct→direct 替换净 +14。
**差别不在模型本身，而在「被替换的那一层与先验的测量场景是否同类」——注意"测量场景"
包含提示词与输入/解码口径**（M 件五项同改即被判为不同类，实测净 −22.4%）。
★此处的"不同类"是**分类判断，不是归因**：M 的六因子共变，**无法**定位是哪一项造成负数。

**★ 方法学教训（本条的真正价值）**：事前把"官方有没有接地指标"当成"模型是否更强"的**代理**，
该代理在本件上**失效**。**证伪一个先验的成本是一次全量，但把它当成"不发车的理由"，
就直接丢掉 101 条。**
须同时强调边界：本次是"**事前判断偏保守**"，**不是**事后调阈值——所有判据（作用域、
闸门、读数口径、止损线）仍**事前写定**；且**不得由此反推"先验无所谓"**（样本仍少，
上表仅 7 个数据点）。

**★ 被撤回的两版说法**：

- **第一版**：称"改动条目与基线的 IoU 分布"可事先预判升级/重掷——依据是 B′（当时记为
  "健康、高重叠"）与 D（p50=0.000）的对照。但直接复算 B′ 的实际剖面后：

  | 杠杆 | 改动条目与基线 IoU | 实测净成功率 |
  |---|---|---|
  | B′（胜） | p50 = **0.000**，<0.3 占 **89.7%** | **+16.1%** |
  | D（负） | p50 = **0.000**，<0.3 占 **80.5%** | **−3.1%** |

  两者剖面**几乎相同、结果相反** ⇒ 该判据在本项目数据上**没有区分力**，撤回。
  （2026-10-03 又把该剖面对 bf16 件与 q38 件做过一次同口径对照：两者几乎同分布、
  结果皆为正 ⇒ 进一步确认无区分力。）
- **第二版**："模型真升级"是必要条件 —— 被上表第四行推翻，见判据 2。

**教训（两次更正共同指向的）**：**结论必须回到原始数据上复算，不能只凭当初的印象**；
且"**先验**"本身也要接受实测的检验——本项目两次修正，方向恰好相反（一次更保守、一次更激进）。

### 结论二：两类负面结果的破坏力量级不同，不可混为一谈

| 负面类型 | 机制 | 实测幅度 |
|---|---|---|
| **重掷** | 把答案换成另一个独立猜测 | **−3.1%**（≈ 掷硬币略偏负：128 条约 62 胜 66 负） |
| **用新外部证据合成候选表** | 外部测量值/另一族模型的候选表当依据 | **−10% ~ −25%**<br>（−24.8% / −18.6% / −23.1% / −10.6%） |

**原因**：重掷**不毁掉已有的正确答案**，只是把它换掉——期望收益接近零；
而"用新外部证据合成候选表"会**连正确的候选一起丢掉**，破坏面大得多。

**工程含义**：在提交机会有限时，**可以容忍重掷型实验**（期望损失小、信息量大），
但应严格避免"新外部证据合成候选表"型实验。

### 结论三：分层小样是"改动率"的精确估计器；前缀不是

在设计新杠杆时，最关键的输入是"改动面有多大"（因为它乘以边际成功率就是收益）。
两种估计方式实测对比：

| 抽样方式 | 小样预测 | 全量实测 | 偏差 |
|---|---|---|---|
| **分层随机**（300 条，按子类型比例） | 改动率 0.077 ／ 一致率 90.2% ／ 输出 `[]` 率 4.3% | **0.077 ／ 89.8% ／ 4.3%** | **≈ 0** |
| 按图名排序的**前缀**（45% / 68% 两次） | 改动面 531 / 518 | **467** | **高估约 10%** |

**结论**：估计改动面必须用小样分层随机抽样，**不能用"跑了一半前缀"外推**——
按图名排序的前缀里分歧条目更密，会系统性高估收益。

## 四、数据格式发现（赛题文档未记载）

实测复赛数据集有**两个格式不同的子群**，文档只描述了其中之一：

| 子群 | 被引用 1295 张中 | 分辨率 | 深度存储 | 红外 |
|---|---|---|---|---|
| `.png` 组 | **1198** | 1920×1080 | `I;16` 单通道 uint16、单位毫米、实测 0–19999 | PNG，三通道近似相同（\|Δ\| ≤ 1） |
| **`.jpg` 组** | **97（7.5%）** | **640×360** | **`RGB` 三通道且逐像素相同**（\|Δ\| = 0）⇒ 实为 **8 位灰度**；JPEG 有损，原始 16 位量程**不可还原** | JPEG，三通道完全相同 |

- 两个子群**内部**三模态同尺寸（.png 组均 1920×1080、.jpg 组均 640×360）⇒ **跨模态对齐性不受影响**。
- **工程陷阱**：直接把 3 维数组交给 `Image.fromarray(arr, mode="L")` 会抛
  `ValueError: Too many dimensions: 3 > 2`，**使那 97 张（7.5%）整批失败**。
  实测一次 300 条小样因此损失 10 条（3.3%）。
- **处置**：对 `.jpg` 组**直通原值、不按未知比例缩放**。
  理由：赛题语义只需"越亮越远"的**单调性**，8 位原值已满足；
  按未知比例换算成毫米等于**凭空造信息**。
- **零回归验证**：`.png` 组（主群 1198 张）的新实现与旧规则输出**逐位相同**。

同时修复的另一个缺陷：图像读取失败时，异常分支未按作用范围过滤，
会把该图**全部**查询（含范围外）一并写入产物——实测带进 16 条越界条目。

## 五、不足之处（如实陈述）

1. **仍未达 0.8**：当前最高 **0.7963**，距 0.8 差 **21 条**（按实测 19.4% ⇒ 需 109 条改动面）。
   离线可做的确定性规则杠杆**已穷尽**：序数侧的上限被**作用域**锁死——序数层现存 414 条错里，
   **760 条的来源是 SoM/det 推算 ⇒ 替换它们属跨机制**（本项目 5/5 全负），
   唯一有正先验的机制够不着；继续提升需再引入一个"**与当前层足够不同**"的定位模型。
   **★ 这一条同时是本次最主要的不足**：事前把"官方有没有接地指标"当成"模型是否更强"的
   **代理**，据此对跨代换模型给出"不给正数、不是到 0.8 的路径"的判断，
   实测却是**全部干预中最高的一次（+19.4%，8.8σ）**。代理失效、判断偏保守，
   是本项目方法学上的实质失误（详见 §三 结论一）。

2. **"可迁移范围"被后续实测进一步收窄（2026-10-03）**：追加一次同机制替换
   （异质模型 72B-AWQ **只补"最新模型未采纳的 429 位"**）得到 **−16.4%（−4.5σ）**。
   ⇒ 机制规律应再收窄为：**只有"框源本身是 VLM 直接输出"的位置可迁移；
   对**补框链工程化填充**做替换属跨机制、为负**（详见 §三 结论一）。
   该结果同时证明：**"补漏通道"（另一位模型去填最新模型的空白）在结构上是空的**——
   残留无框位恰是 VLM 这一类方法做不了的位置，而工程化补链在那里更准。
3. **三模态未被有效利用**：赛题规定的算法输入是三模态，而本方案**主体管线只使用可见光**
   （实证：主管线仅打开 `Images/visible/`）。实验证明给同一模型多喂红外与深度**不产生增量**
   （改动率 0.077 ≪ 所需 0.465，且改动条目与基线 IoU 中位数为 0.000 ⇒ 重掷）。
   **跨模态融合是尚未突破的方向。**
4. **无真值**：全部结论依赖线上提交的单一标量反馈，无法做细粒度的错误分析
   （例如无法回答"某类查询错了多少条"）；归零法只能测到子集粒度。
5. **推理成本**：三图输入的吞吐约 0.33 条/秒，为单图（2.34 条/秒）的 1/7，
   使"多模态输入"路线的验证成本显著升高。
