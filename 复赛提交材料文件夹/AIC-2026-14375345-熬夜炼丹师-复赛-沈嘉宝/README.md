## 二、项目简介

给定同场景**可见光 / 红外 / 深度**三模态图像与一条英文查询，输出目标在可见光图像中的
**归一化边界框** `[x1,y1,x2,y2]`（0~1）。方案为「**预训练多模态大模型零样本推理 +
确定性规则 + 带断言的装配器**」：不做端到端训练，以 Qwen3-VL 系列 / Qwen3.8-27B 承担
感知、以确定性规则承担序数推理、以六桶互斥装配器出件。**仅使用开源模型，未调用任何
闭源在线 API；仅使用赛事官方测试集。**

成绩沿革（线上 ACC@0.5）：0.7459 → 0.7598（序数规则层）→ 0.7786（模型升级/精度修复）
→ **0.7963**（跨代换模型 Qwen3.8-27B 重跑非序数层，519 改动 → 净 +101，19.4%，8.8σ）。

## 七、注意事项

1. **结果文件唯一**：仅 `AIC-2026-14375345-赛题结果文档/` 下的一个 zip 为提交件；
   其余 `.json` 均为管线输入或历史版本，不是备选结果。
2. **字段原样回显**：`visible / infrared / depth / query` 四字段与 `queries.json`
   完全一致，未做任何修改；仅 `bbox` 为预测值。
3. **离线段可逐字节复算，推理段不保证**（浮点归约顺序随硬件/驱动/库版本变化）；
   故记录**实测环境**（`env_record.txt`）而非断言可无限复现。
4. 复现判定标准：分数与 0.7963 差 ±0.005 以内，且各级净成功率落在 10%~19% 区间。
