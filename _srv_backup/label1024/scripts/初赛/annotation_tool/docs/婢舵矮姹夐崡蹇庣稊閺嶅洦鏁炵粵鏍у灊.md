# 多人协作标注功能策划

> 版本：v2（2026-09-14 按代码现状整理）　状态：**已实现**　关联工具：`scripts/初赛/annotation_tool/annotate.py` + `collab.py` + `annotate_ui.html` + `annotate_ui_mobile.html` + `roster.html`；回归测试 `test_collab.py`

## 1. 背景与目标

现有标注工具为单机单实例：一人一个输出目录，`annotations.json` 实时落盘，单实例锁阻止并发。人工标注 9555 条查询（2000 图，每图最多 14 条），是模型评测的评价依据。

目标：支持**任意人数**在**同一局域网**内合作标注同一数据集，标注成果统一汇入同一主库，无并发写冲突，可管理、可回收、可追溯。

## 2. 需求规则（已确认）

| 编号 | 规则 |
|---|---|
| R1 | 全部统一走认领制，不再保留"无会话直接写主文件"的单机模式 |
| R2 | 按**图**分配任务；每张图同一时刻只归一个会话（标注员） |
| R3 | 每人**同时在手图数上限 1 张** |
| R4 | **未领取的图只读**，领取后才能标注 |
| R5 | 标注写入**临时文件**（不直接写主文件）；释放时合并临时文件内容到主文件对应图的位置，**确认合并后删除临时文件** |
| R6 | 访问网页**自动分配会话名称**，按名称分配任务；刷新/重开页面名称不变 |
| R7 | 支持**主动释放**（交还未完成图） |
| R8 | 掉线卡住的图加入**计时释放机制**：10 分钟无心跳自动释放（临时文件合并保留，标注不丢） |
| R9 | **退出保护**：确认图片释放与临时文件合并后才能退出（前端交还 + 后端退出清理） |
| R10 | 加入**认领名单页面**：各会话认领情况、倒计时、状态、全局进度一览 |
| R11 | **本地访问**（127.0.0.1）的会话获得**管理员权限**，可**强制释放**任意会话的图 |

## 3. 总体架构

```
                    ┌────────────────────────── 主机（监听 0.0.0.0） ──────────────────────────┐
 标注员A 浏览器 ──▶ │                                                                          │
 标注员B 浏览器 ──▶ │  annotate.py（单进程 ThreadingHTTPServer，多会话并发）                    │
 标注员C 浏览器 ──▶ │   ├─ 会话表：cookie 识别 + 管理员判定（127.0.0.1）                        │
 管理员(本机) ──▶   │   ├─ assignment.json：图 → 会话认领关系（持久化）                         │
                    │   ├─ tmp_<会话名>.json：各会话临时标注（按图整体状态）                    │
                    │   ├─ annotations.json：主库（释放时合并写入，原子替换）                  │
                    │   └─ 接口：session / claim / release / heartbeat / save / roster /        │
                    │              admin_release / stats / export / group / img               │
                    └──────────────────────────────────────────────────────────────────────────┘
```

- 一个进程服务全部会话；会话身份只靠 cookie，无需启动参数
- 数据文件全部在统一 `--out-dir` 下，主库即最终合并结果，无需再 merge
- 兼容旧单机用法被移除（R1）：所有标注必须经会话 + 认领

## 4. 核心机制设计

### 4.1 会话名称（R6）

- 首次访问标注页 → `GET /api/session`：生成 `标注员-<4位随机>`（如 标注员-7f3a）→ `Set-Cookie: annotator=<名>; Max-Age=长有效期`
- 后续所有请求携带 cookie 识别身份；刷新/重开页面名称不变，成果归属稳定
- 换浏览器 / 换设备 = 新会话名，互不影响

### 4.2 认领与只读（R2 / R3 / R4）

- 打开标注页**自动认领**一张图（"自动认领"开关默认开启；未开启则只读浏览，可手动认领），上限 1 张，认领即进入可标状态
- **认领选取逻辑**：从"**未标注且未认领**"的图中随机领取——判定"未标注"以查询为单位：图片上还有任一**未标注（待标注）**的查询即视为未标注（即使该图已标过部分查询，可被继续认领补标），已认领的图不会重复领取；无符合条件的图时提示"暂无未标注且未认领的图片"
- 可浏览任意图：未认领图、他人认领图均可查看（**只读**），但保存被拒并提示"该图未领取 / 由 标注员-X 标注中"
- 手动"认领此图"：仅当当前无在手图时可用；已有在手图时提示先交还；支持**回退到上一个认领过的图**（认领历史栈）
- 标完本图全部查询 → 弹"交还并领下一张"一键

### 4.3 临时文件与合并（R5）

- 认领图时，以主文件该图现有标注为**基线**加载；标注写入 `tmp_<会话名>.json`（按图整体状态：该图全部查询的 status + bbox，含未修改的基线项）
- 释放（主动 / 标完 / 计时 / 强制）时：
  1. 将临时文件内容**按图整体替换**主文件对应图的位置
  2. **确认合并成功**（写盘校验通过）后删除临时文件
  3. 清除该图认领记录，图回池
- 主文件写操作沿用原子替换（临时文件 + rename），进程内加锁防多请求竞态
- 合并无冲突前提：认领期间该图他人只读，主文件对应图不会被并发修改

### 4.4 计时释放（R8）

- 前端每 **60 秒** `POST /api/heartbeat`（标注操作时也隐式触发），服务端更新 `last_active`
- **10 分钟**无心跳 → 自动释放：合并临时文件 → 删临时文件 → 图回池（**合并保留，掉线者已标内容不丢**；临时文件为空时直接删）
- 前端显示当前图剩余持有时间倒计时，最后 2 分钟黄色警告

### 4.5 退出保护（R9）

| 层 | 机制 |
|---|---|
| 主动交还 | 前端"交还此图"按钮 = 释放 + 合并 + 删临时文件；提供"交还并退出"（成功提示后才可安全关闭页面） |
| 关页面兜底 | `beforeunload` 尽力 POST 交还（不保证送达）；真正兜底 = 心跳停止后的 10 分钟计时释放 |
| 后端退出（Ctrl+C） | 遍历所有未释放会话 → 合并临时文件 → 确认全部成功 → 清理 assignment → 才退出；任一步失败则提示并拒绝退出 |

### 4.6 管理员与强制释放（R11）

- 请求来源 IP 为 `127.0.0.1` / `::1` → 会话标记为管理员（写入会话表），前端显示"管理员"标记
- 认领名单页对任意会话显示"**强制释放**"按钮：对该会话认领图执行完整释放流程（合并 → 删临时文件 → 回池），并记录释放日志
- 被强制释放的会话：下次心跳 / 操作时服务端返回"图已被释放"，前端提示并自动重新认领
- 认领名单页支持管理员**删除会话**（先强制释放其在手图再删记录，确认框提示累计条数不可恢复）

### 4.7 认领名单页（R10）

- 独立页面 `roster.html`（与标注页同目录），每 5 秒轮询 `GET /api/roster`
- 展示：
  - 各会话：名称 / 管理员标记 / 认领图 / 认领时间 / 最后活跃 / **剩余时间倒计时** / 状态（活跃 · 超时待释放 · 空闲）
  - 全局：总进度（done/skipped/pending）、各会话完成数、未认领图数
  - 管理员额外：强制释放按钮 + 释放日志

## 5. 数据模型

### assignment.json（认领关系，持久化）

```json
{
  "Images/visible/001038.png": {
    "worker": "标注员-7f3a",
    "claimed_at": 1750000000,
    "last_active": 1750000360,
    "status": "active"
  }
}
```

### tmp_<会话名>.json（会话临时标注）

```json
{
  "image": "Images/visible/001038.png",
  "data": {
    "001038_001": { "bbox": [0.1, 0.2, 0.3, 0.4], "status": "done" },
    "001038_002": { "bbox": null, "status": "skipped" }
  }
}
```

### 会话表（`sessions.json`，内存 + 持久化）

```json
{
  "标注员-7f3a": {
    "is_admin": false, "created_at": 1750000000, "last_seen": 1750000360,
    "display_name": "标注员-小明",
    "done_count": 12,
    "claim_stack": ["Images/visible/001038.png", "Images/visible/001037.png"]
  }
}
```

- `display_name`：显示名（`/api/rename_session` 修改，前端 localStorage 自动沿用）
- `done_count`：有效标注条数（`status=="done"` 且有 4 数 bbox，不含跳过），释放时在锁内累加、精确落盘；旧会话启动时按 release_log 一次性回填（log 只留最近 200 条，迁移值为近似，此后精确）
- `claim_stack`：认领历史栈（支持回退到上一个认领图）

## 6. 接口设计

| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/session` | GET | 分配/读取会话名（cookie），返回名称 + 是否管理员 |
| `/api/bootstrap` | GET | 会话 + 全局统计 + 在手图 + 认领栈可回退标记（首页初始化） |
| `/api/claim` | POST | 认领一张未认领图（默认：未标注且未认领随机；可指定 `image` 认领具体图） |
| `/api/claim_back` | POST | 回退到上一个认领过的图（认领历史栈，释放当前图并重新认领目标） |
| `/api/release` | POST | 主动交还当前图（合并 → 删临时文件 → 回池） |
| `/api/heartbeat` | POST | 更新 last_active；返回当前图归属状态（含"已被强制释放"信号） |
| `/api/save` | POST | 保存/跳过当前查询 → 写入临时文件；校验认领归属，越权返回 403 |
| `/api/jump` | GET | 跳到下一个未标注（含跳过）查询，可跨图 |
| `/api/rename_session` | POST | 修改会话显示名（≤20 字符，全局唯一） |
| `/api/roster` | GET | 名单数据（会话/显示名/已标条数/认领/倒计时/状态 + 全局进度 + 释放日志） |
| `/api/admin_release` | POST | 管理员强制释放指定会话（校验 is_admin） |
| `/api/admin_delete_session` | POST | 管理员删除会话（先强制释放其图，校验 is_admin） |
| `/api/stats` | GET | 进度统计（合并视图：主文件 + 各临时文件） |
| `/api/export` | GET | 导出答案（合并视图生成 answer.json / answer_full.json / answer_full.zip；**数量不完整时拒绝生成**） |
| `/api/import` / `/api/import_clear` / `/api/imported` | POST/GET | 导入机器标注（预测 bbox / 完整提交 / zip）、清除导入、读取导入信息（仅管理员） |
| `/api/score` | POST | 提交结果与人工标注比对（ACC@0.5 + Mean IoU + 错误明细，仅管理员） |
| `/api/group?image=` | GET | 读取图与查询（含只读标记：是否可编辑 / 归属会话 / 双语查询 / 机器框） |
| `/img?path=` | GET | 图片服务（原逻辑） |

## 7. 前端设计（annotate_ui.html）

- 顶部：会话名（可改名）+ 管理员标记；全局进度；当前图剩余时间倒计时（最后 2 分钟黄色警告）
- 操作区：保存（A）/ 采用机标（S）/ 缩放（Q/W 以框为焦点）/ 适应（E）/ 清除（Del）/ 跳过（按钮）/ 跳到未标注（J）——保留现有快捷键
- 新增：**交还此图**按钮、自动认领开关（默认开）、**回退上一认领**、图片名称搜索跳转、导入/比对/导出（仅管理员）、自动改名沿用（localStorage）
- 只读态：当前图未认领或属他人 → 界面只读提示条，保存/采用按钮禁用；未认领图可点"认领此图"
- 首页/名单页入口链接（roster.html）
- **移动端**：独立页面 `annotate_ui_mobile.html`（服务按 UA 自动分发，`?view=mobile|desktop` 可强制）：单指画框 + 四角手柄调框 + 双指捏合缩放/平移，底部操作栏（保存·采用·+·−·适应·交还·跳过），☰ 菜单收纳次要功能

## 8. 边界与风险（已知）

| 边界 | 处理 |
|---|---|
| 同一浏览器多标签页 = 同一会话 | 可同时编辑（临时文件原子写、最后写者胜）；建议一人一标签页 |
| 关页面不点交还 | 10 分钟计时释放兜底，成果合并保留 |
| 主文件该图已有旧标注（认领前遗留） | 以临时文件为准整体替换（认领期间仅认领人可写该图） |
| 会话名随机碰撞 | 生成后查会话表去重 |
| 强杀后端进程 | 未合并的临时文件与认领记录残留在盘上；**下次启动自动恢复**：遍历残留认领记录 → 合并临时文件到主文件 → 删除临时文件 → 清除认领记录（图回池），并打印恢复条数；无认领归属的孤儿临时文件仅打印警告、不自动合并（避免误合并旧数据） |
