# 人工标注工具使用说明

为测试集图片人工标注真值 bbox（评价依据），生成可直接供 `scripts/evaluate.py` 评测的答案文件；并将模型提交结果与人工标注比对生成分数。

## 1. 运行标注服务

```bash
.venv\Scripts\python.exe scripts\初赛\annotation_tool\annotate.py
```

启动后自动打开浏览器（http://127.0.0.1:8765），按 Ctrl+C 停止服务（停止前自动合并全部在手的临时标注）。

> 注意：同一输出目录（默认 `scripts/初赛/annotation_tool/outputs/annotations`）同一时间只能运行一个标注服务，重复启动会被拒绝并提示；如需并行标注请用 `--out-dir` 指定不同目录。

**多人协作**：服务监听 `0.0.0.0`，局域网内其他电脑可直接访问 `http://<本机IP>:8765/` 参与标注（Windows 防火墙首次可能弹窗，请允许 Python 通信）。各浏览器访问时自动获得唯一会话名（`标注员-xxxx`，cookie 持久，刷新/重开不变）；**本机（127.0.0.1）访问的会话为管理员**，可在认领名单页强制释放他人图片、删除他人会话。认领名单页：`http://127.0.0.1:8765/roster.html`。

**前端热更新（R1）**：主页面与认领名单页（`annotate_ui.html` / `roster.html`）**每次请求从磁盘读取**，修改前端文件后**无需重启服务**，标注员刷新浏览器（或重开页面）即可看到新版；响应带 `Cache-Control: no-store`，浏览器不会缓存旧页面。后端代码（`annotate.py` / `collab.py`）与 `translations.json` 的修改仍需重启服务生效。

## 2. 标注流程

0. **认领制**：每人同时在手 1 张图片，未认领/他人图片为只读（只读横幅提示，不能画框保存）。打开页面自动恢复在手图片；**无在手图片时自动加载第一张图，可正常只读浏览**（用"← 上一图 / 下一图 →"翻页，未认领图可点"认领此图"认领当前显示的图片，他人标注中的图片不能认领），随时可点顶部"认领下一张"按钮认领下一张未认领图开始标注。**标完本图自动交还**；"自动认领"开关（默认关闭）勾选后，标完本图或管理员强制释放后自动认领下一张，否则只交还、由自己决定认领哪张。**自动认领/认领下一张只从"未标注且未认领"的图片中随机领取**：判定"未标注"以查询为单位——**图片上还有任一未标注（待标注）的查询即视为未标注**，即使该图已被标过部分查询；当前被认领的图片不会自动领取。这样部分标注的图也能被其他标注员继续认领标注，直到全图查询标完；若没有符合条件的图片会提示"暂无未标注且未认领的图片"，此时需指定认领具体图片。
1. 页面按图分组展示：主图为可见光（RGB），可勾选叠加红外 / 深度辅助判断（透明度可调，快捷键 2 / 3）。
2. 支持缩放与平移：**滚轮缩放**（以光标为中心，上限 12 倍），**空格 / 鼠标中键拖拽平移**，右上角按钮或快捷键缩放（`Q` / `W` 缩放、`E` 适应窗口）。按钮与 `Q` / `W` 缩放**以当前标注框为焦点**（无框时以画布中心）；滚轮仍以光标为焦点。缩放不影响画框精度，坐标始终按原图像素换算。
3. 右侧显示当前查询文本（**英文原文 + 中文翻译双语显示**，中文为副行灰色小字；查询序号芯片悬停也会显示双语提示）。若某条描述没有对应翻译，则只显示英文。翻译数据在 `scripts\初赛\annotation_tool\translations.json`（8829 条唯一英文描述 → 中文），需要修订译文时直接修改该文件后重启服务即可。用鼠标在图上**拖拽画框**，覆盖目标即可。
4. 每张图最多 14 条查询，点击序号芯片或 ← / → 切换；框会实时显示在图上。顶部"**跳到未标注**"按钮或快捷键 **J**：从当前查询向后跳到下一个未标注项——**包含被跳过的查询**（跳过 ≠ 完成，仍会再次跳到，方便回头补标或复查），无未标注项时提示"全部已标注"。
5. 快捷键：

   | 按键 | 作用 |
   |---|---|
   | 拖拽 | 画框 |
   | 滚轮 | 缩放（以光标为中心） |
   | 空格 / 中键 + 拖拽 | 平移 |
   | A | 保存当前框并跳到下一条 |
   | S | 采用机标（将当前查询的机器框直接保存为人工标注） |
   | Q / W | 放大 / 缩小 |
   | E | 适应窗口 |
   | Del / Backspace | 清除当前框 |
   | J | 跳到下一个未标注查询（**含跳过项**） |
   | ← / → | 切换查询 |
   | 2 / 3 | 叠加红外 / 深度 |

6. **移动端适配（手机 / 窄屏 ≤768px）**：桌面端与移动端为**两个独立页面**——服务按浏览器 UA 自动分发（手机访问直接进入移动版），也可用 `?view=mobile` / `?view=desktop` 强制指定（便于测试）。移动版为竖排布局：顶部为会话名 / 进度 / ☰ 菜单，图片区占上部（62vh），查询与芯片列表在下方（芯片横向滚动），**底部固定操作栏**（按钮自适应等分）：**保存 · 采用机标 · 放大 + · 缩小 − · 适应 · 交还 · 跳过**。**☰ 菜单平时隐藏、点击展开**，收纳：认领名单与正在标注滚动区、认领下一张、跳未标注、清除、图片搜索、上一图 / 下一图、自动认领开关、红外 / 深度叠加与透明度、导入 / 比对 / 导出（仅管理员）。移动版不提供回退入口（桌面保留）。**触控操作**：单指拖动画框；选中框显示四角手柄，单指拖角调整框大小；**双指捏合缩放（以双指中心为焦点）、双指拖动平移**（只读时同样可用）；画布已禁用浏览器手势（`touch-action:none`），高分屏自动按设备像素比适配。桌面版功能与快捷键不变。

7. 每条保存后写入**本会话临时文件**（`tmp_<会话名>.json`），交还 / 10 分钟超时 / 管理员强制释放 / 服务退出时合并进主文件并删除临时文件。顶部显示**剩余时间倒计时**（< 2 分钟变红），前端每 60 秒心跳续期。**保存 / 采用机标后自动适应窗口**。
8. **退出保护**：关闭页面自动尽力交还（未成功则 10 分钟超时兜底）；服务端 Ctrl+C 会先合并全部在手图片的临时标注再退出。

## 3. 相关文件

标注工具文件全部位于 `scripts/初赛/annotation_tool/`（由根仓库 git 管理），另依赖数据集输入与评测脚本：

| 文件 | 作用 |
|---|---|
| `scripts\初赛\annotation_tool\annotate.py` | 标注工具主程序，三个入口：默认启动标注服务、`score` 子命令比对提交结果、`gen-machine` 子命令生成机器标注 |
| `scripts\初赛\annotation_tool\collab.py` | 多人协作核心模块：会话分配、认领、心跳、释放合并、超时清理、退出保护 |
| `scripts\初赛\annotation_tool\annotate_ui.html` | 标注界面（前端），由 annotate.py 从同目录加载，无需单独部署或手动打开 |
| `scripts\初赛\annotation_tool\roster.html` | 认领名单页（前端），5 秒自动刷新；管理员（本机访问）可强制释放、删除会话 |
| `scripts\初赛\annotation_tool\translations.json` | 查询描述的离线中译表（8829 条唯一英文描述 → 中文），服务启动时加载；缺失或损坏时自动降级为仅英文显示 |
| `scripts\初赛\annotation_tool\cancelled_queries.json` | **取消标注清单**：`{note, qids, queries}`，人工确认存在重大错误翻译的查询 qid 列表。列入的 qid 在界面标记"已取消：翻译错误，不作为评测依据"，统计口径与完整性校验均将其排除，导出答案时剔除（该条不做真值），已有标注数据保留不删 |
| `scripts\初赛\annotation_tool\test_collab.py` | 多人协作回归测试脚本（双会话全流程，独立 out-dir + 端口运行，不触碰真实标注） |
| `scripts\evaluate.py` | 评测脚本，消费 `answer.json` 对提交结果打分（标注工具生成的答案文件与其格式兼容） |
| `dataset\queries\queries.json` | 查询定义：9555 条 `{qid: {visible, infrared, depth, query}}`，标注任务来源 |
| `dataset\Images\visible` / `infrared` / `depth` | 三模态图像各 2000 张（1903 张 png 1920×1080 + 97 张 jpg 640×360） |

> `scripts/` 下其余文件（infer.py、export_submission.py、smoke_test.py 等）属于项目其他流程，与标注工具无关。

### 3.1 运行可能生成的文件

以下文件由标注工具在运行过程中生成或更新，默认落在 `scripts/初赛/annotation_tool/outputs/annotations/`（可用 `--out-dir` 指定）：

| 文件 | 生成时机 | 说明 |
|---|---|---|
| `annotations.json` | 标注合并时原子更新（交还 / 超时 / 强制释放 / 退出） | 人工标注主文件（合并视图的数据源之一） |
| `tmp_<会话名>.json` | 标注服务运行中，每保存一条即原子更新 | 会话临时标注：`{image, data:{qid:{bbox,status}}}`；交还/超时/退出后合并并删除 |
| `sessions.json` | 浏览器首次访问 | 会话表：`{会话名:{is_admin, created_at, last_seen, done_count}}`；`done_count` 为**该会话累计有效标注条数**（`status==done` 且有 4 数 bbox，不含跳过），交还合并时在锁内累加并落盘；历史（升级前）数据在首次启动时用 `release_log.json` 的 merged 近似回填一次（含跳过、仅最近 200 条，之后口径精确） |
| `assignment.json` | 认领/交还时更新 | 认领表：`{image:{worker, claimed_at, last_active, status}}` |
| `release_log.json` | 每次释放/合并时追加 | 释放日志（保留最近 200 条）：图片、会话、原因（release/timeout/admin/shutdown）、合并条数 |
| `answer.json` / `answer_full.json` | 点击"导出答案"时生成 | 答案文件（合并视图：主文件 + 全部在手临时文件；仅已标注项 / 含三模态与 query 的完整格式） |
| `answer_full.zip` | 点击"导出答案"时生成 | **可直接提交的提交包**：`answer_full.json` 压缩为 zip（结构与官方提交格式一致：`{qid: {visible, infrared, depth, query, bbox}}`，仅 bbox 为人工标注，其余字段原样保留；bbox 已归一化、无反向/越界）。**`cancelled_queries.json` 中列出的 qid 不会出现在答案中** |
| `imported_annotations.json` | 导入标注、或 `gen-machine` 子命令 | 机器标注；"清除导入"时删除 |
| `score_report.json` | 界面"比对提交结果"或 `score` 子命令 | 比对分数报告（ACC@0.5、Mean IoU、错误明细） |
| `.lock` | 服务启动时创建 | 单实例锁文件；正常退出后文件仍留在目录中（空文件），不影响使用，备份时建议删除 |
| `annotations.json.tmp` | 保存瞬间的原子替换临时文件 | 正常情况不残留；若进程被强杀可能残留，可安全删除 |
| `scripts\初赛\annotation_tool\outputs\backup\annotations_backup_YYYYMMDD\` | 手动备份（见第 5 章） | 已有人工标注的完整快照 |

> 比对功能只**读取** `outputs/` 下的 `predictions*.json` / `submission*.json`（模型推理 / 提交流程生成，非本工具产物），不修改它们。

## 4. 输出目录与文件

默认输出到 `scripts/初赛/annotation_tool/outputs/annotations/`（可用 `--out-dir` 指定）：

| 文件 | 内容 |
|---|---|
| `annotations.json` | 标注工作状态（已标注 / 跳过的原始数据，断点续标依据） |
| `imported_annotations.json` | **机器标注**（导入的模型预测框），`{"name": 来源文件名, "data": {qid: [x1,y1,x2,y2]}}`，与人工标注**独立保存** |
| `answer.json` | 答案文件：`{qid: {"bbox": [x1,y1,x2,y2]}}`，仅含已标注项，归一化坐标，**独立保存**，不随提交结果变化 |
| `answer_full.json` | 含 visible / infrared / depth / query 原始字段 + bbox 的完整格式，便于对照提交包 |
| `answer_full.zip` | **直接提交包**：将 `answer_full.json` 打包为 zip；**导出前检查查询数量完整**——未标注/跳过/无效 bbox 均视为未完成，缺失时拒绝导出并提示"还差 N 条"（提交要求所有查询都有有效 bbox，跳过条目无 bbox 无法提交），全部完成才生成。**完整性口径已排除 `cancelled_queries.json` 中取消标注的 qid**（取消项不要求标注、不计入缺失、不会出现在答案中） |
| `score_report.json` | 提交结果与人工标注比对后的分数报告（含逐条 IoU 与错误明细） |

## 5. 导入模型预测标注（人机对比）

服务启动时会自动加载输出目录下的 `imported_annotations.json`（若存在），将模型预测框作为"机器标注"展示，与人工标注同屏对比、互不覆盖：

- 图上以**蓝色虚线**绘制机器框（角标"机"），人工框为橙色实线；查询序号芯片有机器框时带**蓝点**。
- 右侧查询面板新增"**机标**"行：显示机器框归一化坐标，若该条已有人工框则附实时 **IoU**（人工框与机器框的交并比），方便逐条判断机器预测质量。
- 操作区新增"**采用机标**"按钮（蓝色，仅当前查询有机器框时可用）：一键将当前查询的机器框**直接保存为人工标注**（写入 `annotations.json`，状态记为已标注并自动跳到下一项），用于快速采信机器预测结果；如需调整仍可先拖拽修改再保存。
- 顶部"**导入标注**"按钮可随时导入模型结果，支持三种文件：**预测 JSON**（`{qid: [x1,y1,x2,y2]}`）、**完整提交 JSON**（`{qid: {visible, infrared, depth, query, bbox}}`，即官方提交格式）、**zip 提交包**（内含 `submission.json` / `answer.json`，自动提取）。导入后立即刷新展示，并提示**格式与统计**：`已导入 完整提交格式/预测 bbox 格式 N 条（范围内 M · 超出范围 X · 无效 Y）`；"**清除导入**"按钮恢复无机器框状态。导入内容只写入 `imported_annotations.json`，不影响人工 `annotations.json` / `answer.json`。

生成机器标注文件（命令行）：

```bash
.venv\Scripts\python.exe scripts\初赛\annotation_tool\annotate.py gen-machine --predictions outputs\submission_xxx.json --out-dir scripts\初赛\annotation_tool\outputs\annotations
```

| 参数 | 说明 | 默认 |
|---|---|---|
| `--predictions` | 模型提交 JSON 路径；缺省时自动选取 `outputs/` 下最新的 `predictions*.json` / `submission*.json` | 自动 |
| `--out-dir` | 输出目录 | `scripts/初赛/annotation_tool/outputs/annotations` |
| `--skip-done` | 跳过人工已标注的 qid（用于只生成"剩余标注"） | 关闭（默认全量） |

**人机区分**：人工标注始终在 `annotations.json` / `answer.json`，机器标注独立存于 `imported_annotations.json`；两者加载、保存、清除互不影响，便于人工检查机器结果。

**备份**：开始导入 / 批量操作前，建议先备份已有人工标注——将 `scripts/初赛/annotation_tool/outputs/annotations/` 整体复制为 `scripts/初赛/annotation_tool/outputs/backup/annotations_backup_YYYYMMDD/`（删掉目录内 `.lock` 文件即可）。已有备份：`scripts/初赛/annotation_tool/outputs/backup/annotations_backup_20260911/`（备份时与当时的 `annotations.json` 字节级一致；人工标注持续新增，如需最新备份请按上方说明重新复制）。

评测示例：

```bash
.venv\Scripts\python.exe scripts\evaluate.py --predictions outputs\predictions.json --ground_truth scripts\初赛\annotation_tool\outputs\annotations\answer.json
```

## 6. 提交结果比对（生成分数）

两种方式，均与人工标注结果独立比对，不修改答案文件：

**方式一：浏览器界面**（标注服务运行中）
点右上角"比对提交结果"，自动扫描 `outputs/` 与输出目录下的 `predictions.json` / `submission.json` 并比对，弹出分数面板：ACC@0.5、Mean IoU、正确样本数、错误样本明细（qid + 预测/标注 bbox）。

**方式二：命令行**

```bash
.venv\Scripts\python.exe scripts\初赛\annotation_tool\annotate.py score --predictions outputs\predictions.json
```

| 参数 | 说明 | 默认 |
|---|---|---|
| `--predictions` | 提交结果 JSON 路径（必填），兼容 `{qid: [x1,y1,x2,y2]}` 与 `{qid: {…, "bbox": […]}}` 两种格式 | — |
| `--answers` | 人工标注答案 JSON | `<out-dir>/answer.json` |
| `--threshold` | IoU 阈值 | `0.5` |

输出：样本数（两文件共有 qid）、ACC@0.5、Mean IoU、错误样本（IoU 升序，前 20 条），报告同时保存到 `score_report.json`。


## 8. 多人协作机制

| 规则 | 说明 |
|---|---|
| 会话 | 访问页面自动分配会话名 `标注员-xxxx`（cookie 持久）；本机（127.0.0.1 / ::1）访问 = 管理员 |
| 认领 | 全部走认领制：每人同时在手 **1 张**，未认领 / 他人图片只读；未认领图可点"认领此图"认领当前显示图片。同浏览器多标签页 = 同一会话可并发（最后写者胜，建议一人一标签） |
| 认领历史与回退 | 每个会话记录**认领历史栈**（认领过的图片按序去重记录，持久化在 `sessions.json`）；顶部"回退上一认领"按钮：当前在手时释放本图（临时标注合并保留）并回到**上一次认领的图**，无在手时回到**最近认领过的图**；目标图被他人认领时提示失败；无历史时按钮置灰 |
| 自动认领 | 顶部开关（localStorage 持久，**默认开启**）：勾选后**打开网页无在手图时自动认领下一张**、标完本图 / 被管理员强制释放后自动认领下一张；取消勾选则只交还 / 只读浏览，由自己点击认领 |
| 保存 | 写入本会话临时文件 `tmp_<会话名>.json`，不直接改主文件；越权保存（非本会话认领的图）返回 403 提示 |
| 交还 | 主动交还 / 标完自动交还：临时标注**合并进主文件** → 确认合并 → 删除临时文件，再认领下一张 |
| 超时 | 前端每 60 秒心跳；**10 分钟**无心跳自动释放（临时标注合并保留，图片回到未认领池） |
| 强制释放 | 管理员在认领名单页可强制释放任意会话的在手图片（合并保留标注）；释放/合并记录在 `release_log.json` |
| 删除会话 | 管理员在认领名单页可删除任意会话（不能删除当前管理员会话）：有在手图片先强制释放合并，再移除会话记录与临时文件 |
| 退出保护 | 关闭页面自动尽力交还（失败靠超时兜底）；服务 Ctrl+C 先合并全部在手临时标注再退出 |
| 进度与导出 | 顶部进度、导出答案、比对分数均基于**合并视图**（主文件 + 全部在手临时文件） |
| 图片搜索 | 顶部"搜索图名"输入框：输入图片名关键字（如 `000002`，支持路径前缀模糊匹配）实时列出匹配项（最多 8 条），点击或回车跳转该图（未认领/他人图为只读，自己认领的图可继续标注）；Esc 清空并关闭 |
| 权限 | 非管理员（非本机访问）不显示"导入标注 / 清除导入 / 比对提交结果 / 导出答案"按钮，且对应后端接口（`/api/import`、`/api/import_clear`、`/api/score`、`/api/export`、`/api/imported`）返回 403；仅管理员（本机访问）可使用这些与标注无关的功能。**采用机标（s）对所有标注员开放**：机标为管理员导入的共享数据（`imported_annotations.json`），所有会话的图片加载与"采用机标"均可见可用 |
| 改名 | 顶部会话名旁"改名"按钮：任意标注员可设置自己的显示名称（最长 20 字符，不能与其他会话重名），显示在顶部会话名、认领名单与正在标注滚动区；内部会话标识（cookie、临时文件名、认领记录）保持不变。**自动改名**：改名后会记住在浏览器本地（localStorage），下次打开网页若当前会话尚未设置显示名（新会话），自动沿用上次的名字，无需手动改名 |

认领名单页（`/roster.html`）：5 秒自动刷新，显示各会话状态 / **已标条数** / 在手图片 / 认领时间 / 剩余时间 / 全局进度 / 未认领图片数 / 释放日志；管理员会话显示"强制释放"按钮。**已标条数**为该会话累计**有效标注**（有框且非跳过）；升级前的历史数字为 `release_log.json` 近 200 条回填的近似值（含跳过、可能低于实际）。**管理员还可"删除"任意会话**（不能删除当前管理员会话）：删除时若该会话有在手图片会先强制释放并合并标注，再移除会话记录与临时文件；用于清理已不使用的残留会话。**主页面顶部"认领名单"链接右侧**实时显示正在标注的标注员（名称 · 已标条数 · 认领时长，5 秒刷新）：**每名标注员一行，从上往下"一排一排"竖排显示；行数超出显示高度时整体向上滚动，否则静态显示**；无人在标注时显示"暂无标注员在标注"。

## 9. 说明

- 脚本独立运行，仅依赖标准库 + Pillow + numpy（`.venv` 已具备），不依赖项目 `src` 模块。
- 坐标自动夹取到 [0,1] 并排序（反方向拖拽自动纠正），保留 4 位小数；缩放、平移只影响显示视图，不改变归一化坐标精度。
- 描述翻译为离线预翻译（无网络依赖）：服务启动时加载 `scripts\初赛\annotation_tool\translations.json`，文件缺失或损坏时自动降级为仅英文显示，不影响标注功能。
- 服务监听 0.0.0.0（局域网多人协作）；图片接口校验路径防目录穿越。
- 人工标注结果独立保存在 `answer.json`，提交结果比对只读提交文件、只写 `score_report.json`，互不影响。
- 机器标注（`imported_annotations.json`）仅作对比展示与检查用，不参与 `score` 比对，也不写入人工答案。
