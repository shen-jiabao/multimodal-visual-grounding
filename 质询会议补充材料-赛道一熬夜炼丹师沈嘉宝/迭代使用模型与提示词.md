## 二、提示词与推理口径（逐字原文）

### 2.1 三套主提示词（`code/_qwen_full_pipeline.py`）

**① 非序数「直接定位」——本交付件实际使用的唯一提示词（4587 条全部用它）**

```text
Locate the object described below in this image and output its bounding box.
Description: {q}
Output ONLY a JSON array like [{"bbox_2d": [x1, y1, x2, y2], "label": "object"}] where coordinates are integers normalized to 0-1000 (x1,y1 = top-left, x2,y2 = bottom-right).
```

**② 序数「枚举」（SoM 三段法第 1 段）**

```text
Detect ALL instances of "{core}" in the image. Output their bounding boxes as a JSON array of {"bbox_2d":[x1,y1,x2,y2]}, coordinates are integers 0-1000, ordered from left to right. Include partially visible ones.
```

**③ 序数「选号」（SoM 三段法第 3 段）**

```text
The image has {n} objects marked with red numbered circles (1 = leftmost, {n} = rightmost). Based on the numbering, which number corresponds to: "{q}"? Answer with ONLY the number.
```

**④ 三模态「三图输入」（预登记 D 路线用，实测为负、已弃）**

```text
The three images below show the same scene in this fixed order: (1) visible-light colour photo, (2) thermal infrared (brighter = hotter), (3) depth map (brighter = farther, black = invalid depth).
Locate the object described below and output its bounding box in the visible-light image (image 1).
Description: {q}
Output ONLY a JSON array like [{"bbox_2d": [x1, y1, x2, y2], "label": "object"}] where coordinates are integers normalized to 0-1000 (x1,y1 = top-left, x2,y2 = bottom-right).
```

> 代码里有**机器断言**：`THREE_IMG_PROMPT` 与 `FULL_DIRECT_PROMPT` 在 `{q}` 之后的**输出约定必须逐字相同**，
> 否则脚本立即报错——"单变量"不是口头承诺，而是可判定的约束。

### 2.2 枚举重跑的三条备用提示词（`code/_enum_retry.py`，用于枚举召回不足的条目）

```text
P1 = Detect ALL instances of "{core}" in the image. Output their bounding boxes as a JSON array of {"bbox_2d":[x1,y1,x2,y2]}, coordinates are integers 0-1000, ordered from left to right. Include partially visible ones.

P2 = How many "{core}" are visible in this image? Respond with "COUNT: n" as the first line, then output a JSON array of exactly n objects like {"bbox_2d":[x1,y1,x2,y2]} (integers 0-1000) covering every one of them, ordered from left to right. Include small, distant, occluded or partially visible ones.

P3 = List EVERY "{core}" in this image, including small, distant, occluded, partially visible ones and ones touching the image border. Do not stop after the first one. Output a JSON array like [{"bbox_2d":[x1,y1,x2,y2]}], coordinates are integers 0-1000, ordered from left to right.
```

（P2 是"先问数量再逐一出框"，用于抑制"只给一个就收工"；P3 显式要求"不要只给第一个"。
另配 2×2 分块、边长重叠 15% 的 `TILES` 切片提示。）

### 2.3 解码 / 编码 / 并发口径（全局一致，逐级不变）

| 项 | 值 | 出处 |
| --- | --- | --- |
| 温度 | **0.0（贪心）** | `code/_qwen_full_pipeline.py` `make_gen_api()` |
| `max_tokens` | 直接定位 **256**；枚举 **512**；选号 **16** | 各调用点 |
| 并发 | **`QWEN_CONC=8`** | 主管线环境变量（vLLM 侧 `--max-num-seqs 8`） |

| 服务端参数（交付件阶段） | `--tensor-parallel-size 2 --trust-remote-code --max-model-len 8192 --gpu-memory-utilization 0.90 --max-num-seqs 8 --limit-mm-per-prompt '{"image":1,"video":0}' --max-num-batched-tokens 2048 --disable-custom-all-reduce` | `env_record.txt` STAGE-2 |

### 2.4 序数层的"确定性规则"（不用模型，只有几何与文本推算）

`code/_fuse_qwen.py` 是**判据的唯一实现**，序数四层规则全部基于它：

| 层 | 策略（无需模型） | 关键原语 |
| --- | --- | --- |
| `det` | 从**查询文本**里抽序数词与方向（`first/second/third`、`leftmost/rightmost`…），推算"第 k 个"在左→右序列中的位次 | `expected_ordinal_num()`：LTR ⇒ `k`；RTL ⇒ `nc-k+1` |
| `selfsort` | 把枚举候选**按位置重排**后再取第 k 个（不信任模型自报的编号） | `ordered_candidates()`（按 x 升序，容差 0.02） |
| `qfb` | 推算失败时**回退到直接定位框**，而不是用 SoM 选号 | `det_ordinal()` |
| `yaxis` | 上下方向的"第 k 个"（topmost/rearmost）改用 **y 轴**排序 | `ordered_candidates(axes=('y',))` |
