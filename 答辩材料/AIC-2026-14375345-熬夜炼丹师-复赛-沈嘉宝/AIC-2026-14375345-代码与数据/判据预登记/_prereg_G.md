# 预登记（G）：Qwen3-VL-32B-Instruct **bf16** 替换 32B-AWQ（去量化）

- **写定时间**：2026-10-01，**在下载、起服务、出件与提交之前**
- **状态**：权重下载中（66,726,519,322 字节 / 14 分片）；**被"需要 2×40G 或 1×80G"阻塞**
- 判据一经写定不得修改；结果与解读写入跑后实录新的一节。
- **本件与 F 的区别**：F 换的是**范式**（模型只选候选、不画框）；
  G 换的是**权重精度**——同族、同架构、同机制、同提示词，**唯一变化是去掉 4bit 量化**。

> **为什么另立 G**：当前最高件 `result_semi_n32_orddirect`（0.7766）的非序数层
> 用的是 **Qwen3-VL-32B-Instruct-AWQ（4bit）**。bf16 版**从未跑过**。
> 量化误差直接落在坐标回归上，这是一个**尚未检验**的确定性差异来源，故另立。

## 0. 依据

- 到 0.8 的缺口：`0.8 − 0.7766 = 0.0234` → **133 条**
- 已关闭：序数 SoM（−10.6%）｜序数 B′/B2（≈0）｜深度序数轴（−23.1%）｜
  三模态同模型（−3.1%）｜GD 候选池（−18.6%）｜**VLX 选候选（−18.4%，§20.8）**
- 唯一为正的机制：**同族 direct 升级**（8B→32B，+17.6%，即当前 0.7766 的来源）
- ⇒ 同族 direct 还有**两档**没走：**(a) 去掉量化（本件 G）**、(b) 换 235B（C 路线）
  —— (a) 便宜得多（62 GB / 单次全量），先走 (a)。

## 1. 作用范围

**非序数 4587 条**；**序数层 1103 条逐位不动**（保持单变量隔离，使读数可归因）。

## 2. 机制与"单变量"的严格含义

```
Qwen3-VL-32B-Instruct-AWQ（4bit，当前基线） → Qwen3-VL-32B-Instruct（bf16）
```

**严格单变量**：**只换权重**。以下全部**逐字不变**：

- 提示词（`_qwen_full_pipeline.py` 里的 `FULL_DIRECT_PROMPT` 等常量）
- 解码参数、并发（`QWEN_CONC`）、`QWEN_PHASE=A`、`QWEN_ONLY_NONORD=1`
- 数据、序数核心词表（`_ordinal_cores_v3.json`）
- 装配器与六桶闸门（`_assembly_32b.py`）

⇒ 成败只能归因于"量化误差"这一项。

## 3. 事前预期（★不迁移 +17.6%）

**+17.6% 那条先验来自 8B→32B 的真实容量跃升（架构/参数量/能力），
本件是"同一模型的精度修复"，两者不是同一件事，故不迁移。**

| 项 | 判断 |
|---|---|
| 方向 | **弱正**（去量化一般只会减少误差，不会引入新误差）——但**不保证** |
| 量级 | **小**。改动面 = bf16 与 AWQ 给出不同框的条数，预计远小于 8B→32B 的 467 条 |
| 参考算式（**仅作算式，非预期**） | 若改动 200 条、净成功率 +10% ⇒ +20 条 ⇒ **0.7801** |
| 到 0.8？ | **几乎不可能**。要 +133 条，需要改动面 × 成功率远超本机制的合理量级 |

**写定此处以便事后核对：本件若为负，不推翻"同族 direct 升级为正"那条结论**
（那条讲的是**模型升级**；本件是**精度修复**，是另一类干预）。

## 4. 执行顺序（★不可颠倒）

1. **前置核验**：服务报的模型路径必须是 bf16 那个目录（**不是 AWQ**）
   —— 否则整件事退化成"重跑 AWQ"，读数无意义
2. **接线自校验**：`_smoke_qwen32b.py`（与 AWQ 同一条，必须通过）
3. **20 条目检**：确认出框落在目标上（挡"格式对但语义错位"）
4. **全量 4587 条非序数**（复用 `_launch_qwen32b.sh`，仅改输出/日志两个路径）
5. **装配**：`_assembly_32b.py --direct <bf16 产物> --base result_semi_n32_orddirect
   --base-score 0.7766 --ord-correct 689 --base-correct 3730 --zip`
6. 出件（可回退测量件：序数层 + 未改条目锁定）

## 5. 读数口径

```
得分 × 5690 − 689 = 本次非序数桶正确数     （对照 3730）
Δ = 净翻转条数                            1 条 = 0.000176
```
装配器同时给出**改动面**与六桶分布——改动面是解释读数的必要条件。

## 6. 止损

**读数 ≤ 0（即得分 < 0.7766）⇒ 关闭"精度修复"路径**，不再在 32B 上做去量化类尝试。
