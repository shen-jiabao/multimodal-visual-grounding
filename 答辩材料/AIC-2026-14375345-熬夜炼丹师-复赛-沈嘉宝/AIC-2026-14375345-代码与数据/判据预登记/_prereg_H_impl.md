**★ 决定细则的结构事实**：

```
IoU 带宽分布（替换集 94 条）
  [0, 0.5)     换实例     19  (20.2%)   ← 只有这一档有上升空间
  [0.5, 0.9)    框偏移     31  (33.0%)
  [0.9, 0.999)  框微偏     44  (46.8%)
与当前件完全一致（IoU = 1.0）: 0
```

**94 条里 0 条与当前件一致** ⇒ 枚举路径（`ENUM_PROMPT`）与直接定位路径
（`FULL_DIRECT_PROMPT`）产出的框**系统性不同**。故：
**"改动面 94" 是"框被改写的条数"，不是"收益上限"。**
75 条（80%）属**同一物体的框刷新**：无上升空间，只有把 IoU 推到 0.5 以下的风险。

⇒ 方案 A = **把机制收窄到"只修确实选错实例的条目"**。

## §5 已知缺陷（如实登记，本次不修）

**R5（参照物守卫）误判**：正则 `(of|beside|near|by|next to|in front of)\s+the\s*$`
把「**X of the** *leftmost* Y」这种**正常目标**也判成参照物。已识别的误判样例：

```
000743_004  "The face of the topmost ring-tailed lemur"                    ← 目标即 topmost 的狐猴
001037_007  "The partially visible rear of the leftmost silver sedan ..."  ← 目标即 leftmost 车的尾部
```

**处置：本次不修。** 理由——R5 是在测量**之前**写定的，事后修改即为事后调参。
故本件按 R5 原样执行，作用域 144 条（而非可能的 ~150 条）。
**该缺陷作为限制记入结果**；若要修，须另立一次独立冻结的测量并重跑。
