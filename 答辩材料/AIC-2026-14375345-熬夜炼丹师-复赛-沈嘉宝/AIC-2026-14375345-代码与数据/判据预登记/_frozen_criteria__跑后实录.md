## 一、实测修订：作用域 407 → 真实改动面 66

冻结稿 §2 定的作用范围是"不可推算 407 条"，§6 定的预期是 `407 × 25% ≈ +102 → +0.018`。
在**真实产物**上跑过它自己定的三条闸门（§4）后：

| 环节 | 条数 |
|---|---|
| 作用域（不可推算） | 407 |
| 32B SoM 覆盖 | **407 / 407** |
| 其中枚举失败（`n_cands ≤ 1`） | **204（50.1%）** |
| 过闸门 1（候选表 ≥ 2 项） | 203 |
| 过闸门 2（方向与 k 可抽取且 k ≤ 候选数） | 205 |
| 过闸门 3（选中框 `valid_cand`） | 190 |
| **★三条全过** | **120** |
| 其中与基线一致（IoU ≥ 0.5）→ 按规则不动 | 54 |
| **★真实改动面** | **66** |

⇒ **实测口径的预期上界：`66 × 25% ≈ +16 → +0.0029`**
（冻结稿 §6 写的是 `+102 → +0.018`，**相差约 6 倍**。）

**根因（结构性，非模型容量）**：作用域的**一半在 32B 下枚举仍然失败**——
模型被要求 `Detect ALL instances of X` 时只返回 1 个框，而实际实例数 ≥ k。
这与 8B 时期"候选表空 258 条"是**同一病根**；**换更强的模型没有解决枚举召回不足**。

### 7.1 冻结稿 §5 的止损条件**已满足并执行**

> §5：「若这 407 条的**净翻转 ≤ 0**，立即停止，不再扩展。」

实测净翻转 **−7 ≤ 0** ⇒ **止损触发，序数 SoM 路径关闭，不再扩展。**

### 7.2 根因（三条，均为方法学）

**① 先验不可跨机制迁移——这是我在上一轮犯的错。**
17.6% 测自「8B direct → 32B direct」的**同类替换**；而 SoM 是「枚举 → 叠编号 → 选编号」，
**机制不同**。我在 §6.2 与 `_assembly_ord_som.py` 里把这个先验直接套用到本层、写下 "+12 条"，
**这是错误的迁移**。正确的做法是：**因机制不同而拒绝给出正预期**，或明确标注"先验不适用"。
（§6.3 里把它迁移给 **B′** 是正确的——B′ 与测量场景**同类**。两处结论不同，根源就在机制是否相同。）

**② 冻结稿 §3 的机制边界表述有误。**
§3 写"同族升级（8B SoM → 32B SoM）"。但 §二的实证是：作用域 407 条基线
**74% 与 8B 直接框逐位相同、88.7% IoU ≥ 0.5** ⇒ 该批基线为 **direct 而非 SoM**。
故 32B SoM 替换它实为**跨机制**（direct → SoM），正好撞上本项目
"靠新外部证据 / 跨机制的杠杆"禁区——此前 3/3 全负，**现为 4/4**。
⇒ 教训：**"被替换那一层的性质"必须在冻结之前查一次**；本次查了，却把结论写在了"同族"名下。

**③ 结构性限制。** 作用域 50%（204/407）在 32B 下枚举仍失败，SoM 本就只能覆盖一半。

### 7.3 由此确定的事

- **序数侧 SoM 封口**（止损已执行，不再扩展）。
- **B′（32B direct 替换 direct 基线）是不同机制**，17.6% 对它**可迁移**；
  但启用必须**另写一份新预登记**（作用范围 / 机制 / 闸门 / 先验 / 预期 / 止损），
  **不得翻改冻结稿 §3**。此件尚未写。
  **口径已收紧**：§二当时按"作用域 407"粗算改动面 119、上界 +21；现改用**可检验的同机制条件**
  （基线 IoU ≥ 0.999 等于 8B 直接框）筛出，得 **改动面 87**（其中 82 落在 407 内）
  ⇒ 预期 **+15 条 = +0.0027 → ≈0.7769**。粗算高估的原因：407 里有 32 条基线并非 8B 直接框。
  抽样 σ 仅 ±4 条（±0.0006），但**主导风险是难度不同**——17.6% 测自非序数层，
  而本集合是"文本推算失效"的最难子集，故实际可能低于点估。
- **到 0.8 的唯一路径**：非序数层 + 更强定位模型。量化目标：
