目录说明
========

本目录 = 交付件 `result_semi_q38_nonord.zip`（线上 ACC@0.5 = 0.7963）的
可运行代码、中间产物与历史版本件。技术路线为「跨代换模型 Qwen3.8-27B 重跑非序数层」。

本目录即脚本的 AIC_ROOT（所有 Python 脚本经 AIC_ROOT 解析路径，缺省为 code/ 的上一级），
解压后**无需改任何代码**即可运行。

code/            复赛正式链路代码（32 个 Python 脚本）
  ├── remote_shell/     远端起服与闸门 shell 脚本（11 个，原样复制、不做路径注入；
  │                     其中 _get_serve_q38.sh 为交付件级起服脚本）
  └── training_未采用/  训练与评估脚手架（8 个，未采用，仅为环节完整）

复赛数据集-基于大模型的多模态视觉理解与推理/queries/queries.json
                 赛题查询索引（官方提供，未修改，1.2 MB）——键集来源。
                 （数据集图像为大文件，按赛方要求不入包；脚本按此相对路径读取查询。）

submission_zips/semifinal/   各版本提交件（按线上实际得分归子目录：0.7459 → 0.7963）
  ├── SHA256.txt             提交件谱系（各版本 SHA256、读数链）
  ├── 0.7963/result_semi_q38_nonord.json    ★ 本交付件（装配产物，与赛题结果文档/F 的 zip 同源）
  └── 待提交/result_semi_k72b_n519.json      未提交变体（留档，非交付件）

                 本队实例 /root 镜像）+ 服务器取证/（2026-10-15 只读采集原文、
                 6 张证据附图、开发会话时间线）+ 只读清单

结果件与代码的对应关系：
  ../AIC-2026-14375345-赛题结果文档/result_semi_q38_nonord.zip
  由 code/_assembly_32b.py 以 submission_zips/semifinal/0.7786/result_semi_n32bf16_nonord.json
  为底座、装配 _qwen38_direct.json 得到，可离线逐条复算（见 README.md §5 第 3 条，已实测一致）：

  python code/_assembly_32b.py --direct _qwen38_direct.json \
      --base result_semi_n32bf16_nonord --base-score 0.7786 \
      --ord-correct 689 --base-correct 3741 --stem result_semi_q38_nonord --zip
