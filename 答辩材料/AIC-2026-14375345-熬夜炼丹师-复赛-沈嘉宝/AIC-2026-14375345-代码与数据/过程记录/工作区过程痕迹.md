五、复核方式
------------
  在工作区根目录执行：

    Get-ChildItem -Directory | ForEach-Object { "{0,6}  {1}" -f (Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue).Count, $_.Name } | Sort-Object -Descending
    Get-ChildItem -File | Group-Object Extension | Sort-Object Count -Descending | ForEach-Object { "{0,5}  {1}" -f $_.Count, $_.Name }
