## 二、项目简介

给定同场景**可见光 / 红外 / 深度**三模态图像与一条英文查询，输出目标在可见光图像中的
**归一化边界框** `[x1,y1,x2,y2]`（0~1）。方案为「**预训练多模态大模型零样本推理 +
确定性规则 + 带断言的装配器**」：不做端到端训练，以 Qwen3-VL 系列 / Qwen3.8-27B 承担
感知（直接定位）、以确定性规则承担序数推理、以六桶互斥装配器出件。
**仅使用开源模型，未调用任何闭源在线 API；仅使用赛事官方测试集推理。**

成绩沿革（线上 ACC@0.5）：`0.7459 → 0.7598（序数规则层）→ 0.7742 → 0.7766 → 0.7786
→ **0.7963**（跨代换模型 Qwen3.8-27B 重跑非序数层，519 改动 → 净 +101，19.4%，8.8σ）`。

## 七、注意事项

1. **本包的技术路线 = `result_semi_q38_nonord.zip`（0.7963）的技术路线**：
   Qwen3.8-27B 跨代换模型重跑**非序数层**（519 改动 → 净 +101），序数层 1103 条逐位不动。
   其它路线**均不作为交付件路线**：L7 异质模型（72B）仅以「历史留档 / 未提交变体」随包
   （`submission_zips/semifinal/待提交/` 与 `_k*.json`），`复现流程.md`、`技术报告素材_方法学结论.md`
   中的被否路线为如实留档；「27B 共识投票」路线不在本包内。
2. **结果文件唯一**：仅 `AIC-2026-14375345-赛题结果文档/` 下的一个 zip 为提交件；
   `代码与数据/submission_zips/semifinal/` 下的 JSON 为**历史版本件与中间产物**，不是备选结果
   （其中 `待提交/` 为未提交变体，仅供留档）。
3. **字段原样回显**：`visible / infrared / depth / query` 四字段与 `queries.json`
   完全一致，未做任何修改；仅 `bbox` 为预测值。
4. **离线段可逐字节复算，推理段不保证**（浮点归约顺序随硬件/驱动/库版本变化）；
   故记录**实测环境**（`env_record.txt`）而非断言可无限复现。
5. 复现判定标准：分数与 0.7963 差 ±0.005 以内，且各级净成功率落在 10%~19% 区间。
6. **`代码与数据/复赛数据集-基于大模型的多模态视觉理解与推理/` 下只有 `queries/`（查询索引），
   图像目录按赛方要求不入包**——不是数据缺失；本队机器上该数据集为三模态各 2000 张，其中被引用的
   1295 张**缺失 0**（核验见 `代码与数据/过程记录/赛事数据核验.txt`）。
7. **本包内的 `_prereg_M.md` / `技术报告素材_方法学结论.md` 中出现"对方 0.8092"**：
   那是本队为**对表**而复现公开配置的一次实验（M 件，实测 0.7439，净 −298）的**留档**，
   **不是本队的成绩**，也不代表采用了他人成果——本队交付件成绩为 **0.7963**，全部由本队代码产出。
